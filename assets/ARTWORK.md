# Royal Wheelhouse artwork

Created with the built-in ImageGen tool using the approved game-room concept as the visual reference. The project uses local copies, not remote image URLs.

- `palace.png`: A wide enchanted royal palace alcove, midnight plum and violet, purple velvet curtains, engraved gold arch and columns at the edges, castle windows, candles, roses; the center remains clear for the live game. No lettering or UI.
- `word-wheel.png`: A transparent, front-facing circular prize wheel, layered engraved gold rings, amethyst gems, twelve violet and lavender celestial segments, ornamental crown hub. No words, numbers, stand, or fixed pointer; the app supplies its pointer and animates the wheel.
- `curse-crystal.png`: A transparent front-facing glass crystal ball containing coiling lavender mist and a luminous core, with an ornate jeweled gold pedestal. No lettering or interface; the app supplies animated mist, lightning, and live verdicts.
- `cauldron.png`: A transparent, front-facing deep plum enamel cauldron with sculpted gold filigree, jeweled handles, claw feet and luminous violet potion. No spoon or external smoke in the asset: code adds the stirring spoon, rising bubbles and smoke.
- `poison-flask.png`: A transparent front-facing glass flask with a slender open neck, sculpted gold filigree foot, amethyst details, and emerald/violet liquid. Code adds rising bubbles and the pop.
- `tarot-back.png`: A transparent upright card back with purple velvet, engraved gold filigree, amethyst corners, and a celestial sun/moon/crown mandala; no lettering. Code shuffles multiple copies and flips the chosen card to a live name and meaning.
- `magic-mirror.png`: A transparent front-facing oval mirror with a crown crest, elaborate gold filigree, amethyst gems and a calm smoky silver-purple glass center. Code adds ripples, moving mist, and the live challenge.

These are generated production assets rather than screenshots of a working app. The game controls, result text, saving, random selection, and animations are implemented in HTML/CSS/JavaScript.
