# The Sketchy Wheelhouse

From the Royal Wheelhouse GitHub checkout, run `node server.js` and open
[The Sketchy Wheelhouse](http://127.0.0.1:4173/sketchy/). The Pages build includes this
app under `sketchy/`. It stores its own data in the browser.

Open a new dated party. When everyone is ready, spin the shared Artist’s Brief at
the top, then enter an artist's Discord handle.
Use the side menu to reveal their curse status, then Subject, Setting, and Mood.
Creative Twist is required after Mood when cursed. Choose any available extras,
then add the next artist. Copy Party for Discord groups completed assignments by handle.

Use Party Records to correct an assignment or respin a prompt. Any revealed prompt stays
retired until a new party. Prompt Banks accepts one title per line, with an optional cue
after a pipe. Use Backup to export or restore browser data before moving to a new address
or browser profile. When opened over HTTPS or localhost, the app caches its assets for
offline use and supports installation from compatible browsers. Update the cache version
in `sw.js` when changing app assets.
